Installer

Prêt en quelques minutes

Il faut un Mac (macOS 12 ou plus récent) et une connexion Internet le temps de l'installation. Tout s'installe dans ton dossier personnel, sans mot de passe administrateur.

  1. Clone le dépôt

    Dans GitHub Desktop : File → Clone Repository… → URL, puis colle :

    https://github.com/baptistemazas-nutrition/sosie
  2. Lance l'installation

    Dans le dossier cloné (Repository → Show in Finder), double-clique sur Installer Sosie.command. Une fenêtre de Terminal installe l'outil, le coffre fermé à clé, la protection et l'application, puis fait un essai complet sur des données fictives.

  3. Ouvre Sosie

    L'application est dans le Dock et le Launchpad. Choisis Nouveau projet, donne un nom, indique ta base : elle part dans le coffre, le sosie est fabriqué et le projet s'ouvre dans VS Code.

  1. Clone et lance

    Dans l'application Terminal :

    git clone https://github.com/baptistemazas-nutrition/sosie.git ~/Documents/GitHub/sosie && open ~/Documents/GitHub/sosie/"Installer Sosie.command"
  2. Outil seul, sans l'application

    Pour n'installer que la commande sosie (Mac ou Linux) :

    cd ~/Documents/GitHub/sosie && sh installer.sh
  1. Télécharge l'archive

    sosie-main.zip, puis double-clique dessus pour la décompresser.

  2. Ouvre l'installateur

    Fais un clic droit sur Installer Sosie.command → Ouvrir → Ouvrir : macOS demande cette confirmation pour un fichier téléchargé depuis Internet.

Les règles d'or

Six réflexes

🔒Le coffre, et seulement lui

Les vraies données ne vivent que dans ~/Coffre : Sosie les y déplace pour toi.

🚫Le coffre reste fermé

Sosie le referme à clé après chaque action. Ne l'ajoute jamais à une IA, et referme-le si tu l'as ouvert.

✂️Pas de copier-coller

Ne colle jamais une vraie valeur ou un résultat non vérifié dans une conversation.

📂Le projet, pas tout le disque

Ouvre ton assistant d'IA sur le dossier du projet, jamais sur tout le disque : ses consignes (CLAUDE.md, AGENTS.md, GEMINI.md) le guident.

🔢Pas de petits effectifs

Moins de 11 patients dans une case : on regroupe ou on affiche « <11 ».

🧪Le sosie ne soigne personne

Ses chiffres n'ont aucun sens clinique : seuls comptent ceux des vraies données vérifiées.

Questions

Ce qu'on se demande souvent

Ça marche avec quelle IA ?

Avec celle que tu préfères. Un assistant de code ouvert sur le dossier du projet (Claude Code, GitHub Copilot, Cursor, Codex…) lit la fiche du sosie, écrit le script et le teste sur le sosie. Une IA de discussion (ChatGPT, Le Chat de Mistral, Gemini, l'application Claude…) l'écrit à partir de la fiche FICHE_SOSIE.md, que tu lui donnes. Dans les deux cas, elle ne voit que des données inventées et des résultats vérifiés. Les consignes de travail sont écrites dans CLAUDE.md, AGENTS.md et GEMINI.md : chaque assistant lit d'office le sien.

L'IA peut-elle quand même lire mes vraies données ?

Non. Le coffre est fermé à clé dès que Sosie ne s'en sert pas : aucune IA (Claude, ChatGPT, Copilot, Cursor, Codex, Gemini…) ni aucun autre programme ne peut le lire, et Sosie refuse de tourner quand c'est une IA qui le lance. Avec Claude Code s'ajoutent des règles d'interdiction et un bac à sable. L'IA ne reçoit que le sosie (dans donnees/) et les résultats vérifiés (dans resultats_verifies/), et un fichier témoin rangé dans le coffre permet de vérifier la protection. Seule précaution : pendant qu'une action de Sosie tourne, ou quand tu as ouvert le coffre toi-même, il est ouvert ; ne demande pas alors à une IA de fouiller ton ordinateur.

Et si mon script plante sur les vraies données alors qu'il marchait sur le sosie ?

C'est justement prévu : le sosie reproduit les pièges des vraies données (formats, virgules, valeurs manquantes, codes spéciaux) pour que ça arrive rarement. Si ça plante, la vérification transmet le journal d'erreur à l'IA quand il ne contient rien d'identifiant : demande-lui de lire resultats_verifies/ et de corriger.

Quels formats sont pris en charge ?

CSV et TXT (séparateurs, encodages et virgules décimales conservés), Excel (feuilles, en-têtes décalés), SAS (sas7bdat, xpt), SPSS (étiquettes et manquants), Stata, Parquet, Feather, R (rds, RData avec facteurs et dates), SQLite et JSON. Les extractions du SNDS sont gérées (clés de jointure, codes, dates).

Pourquoi Claude Code est-il plus bridé dans mes autres projets ?

Par défaut, Sosie active le bac à sable de Claude Code dans tous les projets, pour qu'aucun ne puisse lire le coffre. Si cela te gêne (écriture hors du projet, git push, certains sites), limite-le aux projets Sosie avec sosie configurer --bac-a-sable projets.

Comment mettre à jour Sosie ?

Ouvre Sosie et choisis Réparer ou mettre à jour sosie : la dernière version est récupérée et tout est réinstallé. Refais ensuite le sosie de tes projets pour profiter des corrections.

Ce que Sosie ne fait pas

Il ne reproduit pas les liens entre variables (corrélations, IMC = poids/taille²) : les analyses sur le sosie n'ont pas de sens, seul le code compte. Une même clé écrite différemment selon les fichiers (P-17 ici, 17 là) ne joint qu'environ la moitié des lignes du sosie.
